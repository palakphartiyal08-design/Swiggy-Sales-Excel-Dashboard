# Swiggy Sales & Delivery Dashboard

## 📊 Project Overview

An interactive Excel dashboard designed to analyze Swiggy sales, orders, ratings, and delivery trends across different cities, states, food types, and time periods.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Visualization

## 📈 Dashboard Features

- Sales performance analysis
- Order analysis
- Rating analysis
- Delivery trend analysis
- City-wise and state-wise performance
- Food-type analysis
- Interactive slicers and filters
- KPI cards for quick business insights

## 🎯 Key Objectives

- Analyze overall sales and order performance
- Identify top-performing cities and states
- Understand food-type performance
- Analyze ratings and delivery trends
- Support data-driven business decisions
